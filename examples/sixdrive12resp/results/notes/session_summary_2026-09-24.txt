BOUNDED SOFTENING: THE NONLINEAR PLANT THAT CANNOT ESCAPE

STARTING POSITION
-----------------
Four nonlinear runs (42, 44, 46, 48) had been taken on softening-CUBIC plant
files and all four ended the same way: overflow in the time integration at
sdynpy_nonlinear_system_virtual_hardware.py:151,

    RuntimeWarning: overflow encountered in power
        return k3s * q ** 3 + c2s * qd * np.abs(qd)

That is escape, not a jump.  A softening cubic gives a FINITE potential well:
the restoring force wn^2 q + k3 q^3 (k3 < 0) reaches zero at

    q_esc = wn / sqrt(|k3|)

and reverses beyond it.  The trap, restated because it is the whole story of
the cubic article: raising |k3| raises the shift linearly and moves the cliff
closer as 1/sqrt(|k3|) at exactly the same rate, so the shift available AT
escape is fixed at 3/8 = 37.5% whatever |k3| is.  With 4-sigma random peaks
that caps the usable shift near 0.5-1%; escapecal's MARGIN=10 put it at
0.375%, and run 48 escaped anyway.  You cannot buy effect with strength.

Four amplitude predictions were made across that campaign and all four were
wrong.  That record is the reason everything below was MEASURED rather than
asserted.

THE IDEA (user's, from a Mathematica/MATLAB SDOF demo)
------------------------------------------------------
A softening stiffness that saturates instead of reversing:

    Ks(x, r) = x * (exp(-1e6*|x/3|) + 0.5*r)

Both factors stay positive for x > 0, so the restoring force never changes
sign.  It saturates onto a residual linear stiffness 0.5*r*K and the potential
keeps opening as 0.5*(0.5r)*K*x^2.  There is no well, so there is nothing to
escape from.  This is not a larger margin on the cubic -- it removes the
failure mode structurally.

TWO CHANGES MADE IN PORTING IT
------------------------------
1. NORMALIZED so g(0) = 1.  In the original Ks'(0) = 1 + 0.5r, so the
   small-amplitude natural frequency is w*sqrt(1+0.5r), not w.  Normalized,
   the small-amplitude modal frequency is EXACTLY the measured wn, which is
   what lets the article start from the same linear FRF it always did.

2. GAUSSIAN kernel exp(-(q/qt)^2) rather than exp(-|q|/qt).  The Gaussian
   matches the cubic term for term at small amplitude,

       g(q) ~ 1 - (1-alpha) q^2/qt^2   <->   k3 = -(1-alpha) wn^2/qt^2
       qt = q_esc * sqrt(1-alpha)

   so escapecal's per-mode calibration maps across unchanged, and the shift
   stays QUADRATIC in level (6 dB -> 4x) instead of linear.  The |q| form has
   a kink at q = 0 and gives a shift linear in level, compressing the contrast
   across a level change -- which is the whole experiment.

Final form:

    g(q) = alpha + (1-alpha) exp(-(q/qt)^2)        alpha = 0.35
    F(q) = wn^2 q g(q)
    nl   = F - wn^2 q = wn^2 q (1-alpha) expm1(-(q/qt)^2)      <= 0

expm1 is exact as q -> 0 and saturates at -1, so the term cannot overflow at
any amplitude.  alpha >= 0.3086 keeps dF/dq positive everywhere (below that
the tangent stiffness dips negative over a band -- still bounded, still no
escape, but jumpy and stiff to integrate).

THE ERROR THE VERIFICATION CAUGHT (this is the important part)
--------------------------------------------------------------
First build targeted 5% shift at 0 dB, sized on the LINEAR modal response.
Time integration measured 29%.  A factor of six.

Two feedbacks were missing, both amplifying:

  1. Softening lowers modal stiffness -> response grows -> softens further.
     For a white force this alone is mild: sigma ~ g^-0.75, fixed point near
     5.8%.
  2. The control drive is SHAPED.  match_trace notches it at each resonance
     to flatten the response.  When the resonance moves it slides off its own
     notch into a much hotter part of the drive spectrum.  THAT is the large
     term, and no white-noise estimate can see it.

Measured response growth from softening alone: sigma(g_target)/sigma(linear)
ran 1.10 - 3.27x at the 5% target.

FIXED-POINT STABILITY -- the real constraint
--------------------------------------------
The loop sigma -> g(sigma) -> sigma(g) has a gain.  Above 1.0 the design
point is UNSTABLE: the plant does not settle there, it jumps past to the
far-softened stable state.  Measured gain vs target, run 40 drive:

    target     max loop gain     modes unstable
     0.20%         0.065              0/33
     0.50%         0.187              0/33
     1.00%         0.507              0/33
     1.50%         0.764              0/33
     2.00%         0.996              0/33   <-- cliff
     3.00%         1.695              3/33
     5.00%         2.650              9/33   <-- the first build; jumped to 29%

The cliff is at 2.0%.  Built at 1.0%, gain 0.507 -- a factor of two of margin.
The builder now ABORTS if gain >= 1 and warns above 0.7.

SYSTEM ID CONTAMINATION -- a finding, not just a setting
---------------------------------------------------------
The shift is quadratic in modal amplitude, and the flat system-ID drive
excites the modes differently from the shaped control drive: measured per-mode
ratio q_sysid/q_control = 1.183 worst case, consistent with the 0.25-1.2 range
escapecal measured.  So at full level the identified FRF carries softening
ALREADY BAKED IN, mode-dependently.

At the 1.0% design: median 0.22%, worst 1.27% (mode 3, 246.9 Hz).
    ==> RUN SYSTEM ID AT -4.5 dB to hold every mode under 0.5%.

This is a candidate explanation for run 48's system ID "looking significantly
noisier than the linear system sysid".  Part of that was very likely not noise
at all -- it was each resonance sitting at a different shifted frequency.

MODE SELECTION -- unresolved
-----------------------------
The chosen rule was "in-band modes only" (100-1000 Hz).  On this plant that is
a NO-OP: all 33 flexible modes lie between 120.0 and 899.5 Hz, so every mode
is softened and there is no linear control group in the measurement.

If a genuine subset is wanted, two options, both a one-line change:
  (a) contiguous sub-band, e.g. soften only above 400 Hz, so the FRF shows a
      visible boundary between softened and linear regions;
  (b) top-N by modal participation.

OPEN CAVEAT
-----------
All of the above is OPEN LOOP against run 40's fixed drive.  In the closed
loop the controller re-notches every cycle, which will change the loop gain in
a direction that cannot be predicted from here -- chasing the resonance could
reduce the slide-off effect or deepen it.  The 2x stability margin exists for
that uncertainty.
